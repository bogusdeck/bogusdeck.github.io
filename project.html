MineMatrix — Rule-guarded Reinforcement Learning environment and agent framework for Minecraft. Uses Mineflayer as a Node.js HTTP bridge to execute discrete actions on a local Minecraft server, guided by hardcoded survival safety rules (Rule Guards). Pairs with a Gymnasium environment and Stable-Baselines3 (PPO) in Python to learn optimal survival policies. Includes an LLM-planner variant (Ollama/qwen2.5) for high-level decision making alongside the pure RL approach.

MineMatrix

SQL Saga — An interactive terminal game that teaches SQL through a narrative mystery story. Progress through chapters by writing real SQL queries executed against an in-memory SQLite database with the challenge's schema and sample data. Get instant feedback with detailed result diffs, a progressive hints system (Ctrl+H), and local progress tracking (XP, streaks, attempts). Built with Bubble Tea (Charmbracelet) for a cross-platform TUI on Linux, macOS, and Windows. Distributable via Homebrew, APT, dnf, and apk.
